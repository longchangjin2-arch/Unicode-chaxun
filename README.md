# Unicode 编码查询

一个功能丰富的 Unicode 字符查询与浏览工具，纯前端单页应用，无需后端服务，开箱即用。

基于 **Unicode 17.0** 标准，内置全部 346 个区块定义。

---

## 功能特色

### 🏠 总览
- 应用首页，集中展示数据统计与快捷入口
- 数据统计：字符条目数、区块数、语言分区数、收藏数、收藏分类数、表情符号数
- 快捷入口：一键跳转到搜索、全部字符、随机字符、分类等所有功能
- 最近动态：最近搜索、最近收藏、最近浏览的字符一览

### 🔍 智能搜索
自动识别输入类型，支持多种查询模式：
- Unicode 编码：`U+4E00`、`0x4E00`、`4E00`（纯数字同样按十六进制解释；超出十六进制范围时自动按十进制，如 `1114111` → U+10FFFF）
- 单个字符优先按字符解释：输入 `a` 得到字母 a 而不是 U+000A
- 按字符查询：输入任意字符即可解析
- HTML 实体：`&#20013;`、`&#x4E2D;`、`&amp;`
- CSS 转义：`\4E2D`
- URL 编码：`%E4%B8%AD`
- 按名称搜索：如 `heart`、`arrow`
- **多码点 Emoji 序列**：国旗 🇺🇳、肤色 👍🏽、组合 emoji 👨‍👩‍👧 等自动识别，显示组合后的完整字符及码点组成

### ⚖️ 字符对比
- 并排对比两个字符的所有属性（各取第一个字符；输入了多个字符会明确提示，不再静默取第一个）
- 高亮差异项
- 支持代理对和不可见字符

### 📊 批量解析
- 粘贴一段文本，逐字符解析全部属性（单次上限 2000 个字符/编码，超出会提示并只解析前 2000 个，可分段粘贴，避免超长文本卡死页面）
- 表格展示：码点、UTF-8、UTF-16、HTML 实体、CSS、URL 编码
- 一键复制任意列，**实时复制预览**（切换列/分隔符时即时更新）
- **编码→字符**反向解析：支持 `U+XXXX`、`\uXXXX`、`\u{XXXX}`、`0xXXXX`、HTML 实体（`&#x4E16;`、`&amp;` 命名实体）、CSS 转义（`\4E16`）、URL 编码（`%E4%B8%AD`）、纯十/十六进制，支持混合文本自动提取
- **自定义分隔符**：预设按钮（`/` `,` `␣` `↵` `∅`）+ 自定义输入框，切换模式时保留设置
- 解码模式显示**拼接结果**，支持一键复制
- UTF-8/UTF-16 字节间始终用 `/` 分隔，避免与字符分隔符混淆
- 代理对自动合并（`\uD83D\uDE00` → U+1F600）

### 🎲 随机字符
- 按语言分区随机（中文、英文、日文、韩文、阿拉伯文等）
- 按 Unicode 区块随机（上传新版本 Blocks.txt 后区块列表自动更新）
- 一次生成 200 个随机字符

### 📂 浏览方式

**全部字符**
- 按 Unicode 码点顺序浏览全部有效字符（懒加载按需分页）
- **默认跳过 C0 控制字符（U+0000–U+001F）**，首屏从 U+0020（空格）开始，不会一进来就是满屏红色警告格；顶部「🚫 跳过控制字符」开关可随时关闭，关闭后从 U+0000 开始、包含全部码点
- 支持跳转到指定页码
- 支持按 Unicode 编码跳转定位，自动高亮对应字符

**分类浏览（手风琴折叠面板）**
- 入口名称「分类」，采用手风琴折叠布局，含两个互斥分组：
- **🌐 按平面（17 个）**：列出 Unicode 17 个平面，每个平面显示码位范围、用途说明、区块数
  - 第 0 平面：基本多语言平面（BMP）
  - 第 1 平面：辅助多语言平面（SMP，含表情、历史文字）
  - 第 2、3 平面：罕用汉字扩展区
  - 第 4–13 平面：预留未分配（显示「暂无区块定义」灰色项）
  - 第 14 平面：辅助特殊用途平面（SSP）
  - 第 15、16 平面：私用区 A/B
  - 点击有区块的平面 → 进入该平面下的区块列表
- **📦 按区块（共 N 个）**：直接列出全部区块（含所属平面标注）
  - 点击区块 → 进入字符浏览（虚拟滚动，DOM 只渲染可视区附近几排，CJK 几万字符的大区块也流畅）
- 同时只展开一个分组，点击标题切换；列表区独立滚动，长列表不影响页面布局
- 上传新版本 Blocks.txt 后，两组数据（平面区块数、区块列表）自动更新
- 区块内提供「返回」按钮，并实时显示 `⭐ X / N 已收藏` 进度

**我的收藏**
- 支持分组视图和平铺视图（平铺采用虚拟滚动，收藏再多也不卡）
- 平铺视图按收藏时间顺序排列（最新收藏的在后面），详情弹窗导航也按收藏顺序翻页

**浏览记录**
- 自动记录最近 200 个查看过的字符

### 📄 字符详情
点击任意字符弹出详情卡片，包含：
- 字符预览 + Unicode 码点（十六进制/十进制）
- UTF-8 / UTF-16 / HTML 实体 / CSS 转义 / URL 编码
- Unicode 类别
- 所属区块（中英文）
- 字符含义（内置字典 + 用户自定义）
- 字典信息（拼音、笔画、部首）
- 不可见字符特殊标记与警示
- 文字放大预览 + 图片导出（PNG / JPG / WebP / SVG）
- **字符导航**：详情弹窗支持前/后切换，键盘 ← → 也可切换（全部字符视图支持跨页导航）

## 个人数据管理

### 收藏功能
- 字符右上角 ★/☆ 图标显示收藏状态（纯状态标识，不可点击）
- **收藏状态与进度**：网格顶部显示 `⭐ 42 / 96 已收藏`，实时反映当前页/当前区块的收藏进度
- **🖱️ 点击收藏模式**：一键切换后，点击字符即直接收藏/取消收藏，不弹详情框（适合快速刷收藏）
- 收藏分类：创建自定义分类，像视频收藏夹一样管理收藏的字符

### 数据编辑
- **自定义字义**：管理模式下编辑字符含义
- **自定义字典**：管理模式下编辑拼音、笔画、部首
- **操作日志**：记录最近的操作行为，便于追溯

### 数据导出/导入
- 支持两种导出方式：
  - **下载**：保存到浏览器默认下载目录
  - **另存为**（Chromium 浏览器）：选择任意保存位置
- JSON 格式，方便备份和分享（含收藏分类）
- 所有个人数据存储在浏览器 localStorage 中，不上传服务器

## 使用方法

### 直接使用
用浏览器打开 `index.html` 即可，无需安装任何依赖。

### 部署上线
将 `index.html` 上传到任意静态网站托管服务即可：
- GitHub Pages
- Vercel / Netlify / Cloudflare Pages
- 任意 Web 服务器（Nginx、Apache 等）

### 上传完整 Unicode 数据（可选）
内置数据包含全部 346 个区块定义，但不含每个字符的详细属性。如需完整数据：

1. 打开设置 → 「从文件更新」
2. 下载以下两个文件（Unicode 17.0.0）：
   - **UnicodeData.txt**：[https://www.unicode.org/Public/17.0.0/ucd/UnicodeData.txt](https://www.unicode.org/Public/17.0.0/ucd/UnicodeData.txt)（约 2.1 MB）
   - **Blocks.txt**：[https://www.unicode.org/Public/17.0.0/ucd/Blocks.txt](https://www.unicode.org/Public/17.0.0/ucd/Blocks.txt)（约 11 KB）
3. 点击「上传 UnicodeData.txt」和「上传 Blocks.txt」

上传后可获得全部 159,801 个字符的名称、类别、大小写映射、双向属性等完整信息。数据存储在浏览器 IndexedDB 中。

**上传 Blocks.txt 后会自动更新的功能**：
- 分类浏览（17 个平面各平面下的区块列表、数量、范围、空平面判定）
- 随机字符的区块选择列表
- 总览页的区块数统计
- 字符详情中的所属区块信息

## 技术栈

- 纯 HTML / CSS / JavaScript（无框架、无依赖）
- CSS Grid + Flexbox 布局
- CSS 变量主题系统（深色/浅色）
- Canvas / SVG 图片导出
- File System Access API（另存为功能）
- IndexedDB 存储 Unicode 数据
- localStorage 存储用户数据
- **虚拟滚动**（窗口化渲染）：大区块/收藏平铺只渲染可视区附近几排格子，占位元素撑出滚动高度，滚动时 rAF 节流更新窗口
- 内嵌 tiny-inflate：字典数据以 zlib+base64 压缩存储，运行时同步解压，文件体积减半

## 更新日志

### 性能与交互优化批次（最新）

- **虚拟滚动全面落地**：大区块浏览、收藏平铺、收藏分类详情三处全部改为窗口化渲染——DOM 里永远只挂可视区上下各 4 排的格子，用占位元素撑出完整滚动高度，滚动时 rAF 节流更新窗口。CJK 扩展区几万字符的大区块从"越滚越卡"变成全程流畅
- **网格悬停高亮性能优化**：原先每格 hover 用 transform + box-shadow + border-color 三属性过渡（两处重复定义叠加），几千格子下蓝光高亮跟不上鼠标。改为伪元素预绘高亮环、hover 只切 opacity（GPU 合成零重绘），删掉上浮位移动画；点击收藏的黄色虚线皮肤同步迁移，并修掉两套高亮叠加问题
- **点击收藏开关修复**：切换模式时按钮文字/样式更新了但 onclick 没跟着翻转，导致开了就关不掉；同时 querySelector 改 querySelectorAll，多个视图的控制栏按钮状态同步
- **详情弹窗精简**：移除「📊 其他属性」区块（双向类别、组合类、分解映射、镜像、大小/小写映射），弹窗到编码信息为止，更低更清爽
- **收藏操作不再刷新页面**：收藏/取消收藏统一走就地 DOM 更新（星星图标、计数、分组），不再触发整页重绘；收藏视图里取消收藏直接移除该格并更新计数
- **文件体积从 8.9MB 减到 3.4MB**：字典明文与压缩版原本各存一份（5.66MB 冗余），删除明文、内嵌 tiny-inflate 运行时解压，功能零损失

### 收尾修复（上一批）

- **「全部字符」首屏不再是一片控制字符**：默认跳过 32 个不可打印的 C0 控制字符（U+0000–U+001F），第一页从 U+0020（空格）开始，标点、数字、字母直接可见。顶部新增「🚫 跳过控制字符」开关，关掉即回到从 U+0000 开始的完整码点顺序（控制字符完全可达）。跳编码到被跳过的码点时会明确提示而不是静默无反应
- **批量解析加单次上限 2000**：表格是逐字符一行渲染的，粘贴几万字会直接卡死页面；现在超限会明确提示"原文共 N 个字符，为避免卡顿仅解析前 2000 个，可分段粘贴"（编码/解码两个模式都生效）
- **字符对比不再静默丢弃输入**：输入了多个字符时给出"只对比各自的第一个字符"的说明；输入框上限从 4 放宽到 8，避免 ZWJ 组合 emoji 被截断

### 使用体验修复批次（上一批）

- **深色模式**：此前手机端侧边栏隐藏了主题开关、且没有任何替代入口，导致**手机上无法使用深色模式**；现在设置面板中新增深色模式开关。同时主题选择会写入 localStorage，**刷新后不再被打回浅色**
- **深色模式可读性**：详情弹窗管理模式下的输入框、标签、分隔线，以及设置面板的邮件卡片等 20 余处内联样式是写死的浅色（内联样式优先级高于 CSS，暗色规则覆盖不到），已全部改为主题变量
- **搜索**：切换识别模式后现在会立即按新规则重解析（原先点了没反应）；返回搜索页时会预填上次的查询词，不用重输
- **搜索结果**：名称搜索命中超过 500 条时，标题与提示会明确说明"仅显示前 500 个"，不再让人以为只有这么多
- **网格**：鼠标悬停格子现在显示字符名称与编码，不打开详情也能辨认
- **分类页**：默认展开"按平面"分组，少点一次
- **详情弹窗**：保存含义/字典、切换收藏后的原地刷新不再把弹窗滚回顶部，也不再重复写入浏览记录和操作日志
- **总览页**：进入时清空字符列表，避免点开"最近收藏"时出现属于上一个视图的翻页导航
- **防误操作**：清除浏览记录、清空操作日志新增二次确认（并提示将删除多少条）
- **随机字符**：数量超出 10–2000 范围时，钳制后的值会回写到输入框（原先输入 5000 时界面显示 5000、实际只出 2000）
- **批量解析**：切换分隔符后，按钮高亮在表格重绘时不再丢失
- **文档与实现对齐**：移除 README 中并不存在的「⭐ 收藏本页 / ⭐ 收藏本区块全部」批量收藏说明与「管理模式 PIN 码」说明（该功能未实现，清空数据的确认框里也已去掉这项），并删除对应的残留死 CSS

### Bug 修复批次（上一批）

- **QQ 群二维码此前完全不可用，现已修复**（三个叠加问题）：
  - 设置面板缺少二维码容器元素（CSS 有 `.qq-group-qr` 但 HTML 没有），`renderQQQRCode()` 直接返回，二维码从不显示
  - Reed-Solomon 生成多项式递推下标写反（`gen[j-1] ^ gen[j]·α^i` 应为 `gen[j] ^ gen[j-1]·α^i`），纠错码字自 ecLen≥3 起全部算错
  - 格式信息表 32 项中有 17 项不是合法 BCH 码字
  - 另外定位图案（对齐图案）表缺少每个版本的最后一个坐标，且画完后未标记 reserved 会被数据位覆盖 —— 实际效果是 v3 一个定位图案都没有
- 批量解析「编码→字符」的**代理对合并此前完全失效**（`\uD83D\uDE00`、`&#55357;&#56832;` 都解析为空）：高位代理被 `pushCp` 直接丢弃，配对永远无法发生
- 详情弹窗「含义」的多行文本不换行：正则 `/\n/` 写成了 `/\\n/`（匹配字面反斜杠+n）
- 总览页「最近搜索」点击无反应（该页没有搜索输入框），且显示的是最旧而非最新的 12 条
- 总览页「最近收藏」显示的是最早收藏的 12 个，改为最新 12 个
- 内联事件引号转义错误：搜索词含 `'` 时生成的 `onclick` 会语法错误、分类名含 `"` 会截断属性；新增 `escapeJsAttr()` 统一处理
- 分类详情的标签页标题改后不还原；放大预览打开时 ←/→ 会切到背后的字符、Esc 关错层；设置面板现在也支持 Esc 关闭
- 无效码点不再写入浏览记录与操作日志
- C1 控制字符（U+0080–U+009F）补齐不可见标记，此前显示为空白
